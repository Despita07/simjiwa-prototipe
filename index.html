Lingkungan 3D interaktif
Memuat lingkungan 3D…

Seret untuk memutar • Gulir atau cubit untuk zoom • Klik karakter dan furnitur untuk mengamati.

Pilih objek di ruangan atau gunakan tombol pengamatan di bawah.

Kontrol mouse: seret untuk memutar, gulir untuk zoom. Pada ponsel, seret satu jari dan cubit dengan dua jari. Jika perangkat mendukung WebXR, tekan “Masuk mode VR”. WebXR memerlukan HTTPS dan izin browser; penyematan Google Sites dapat membatasi akses headset. Model karakter bergaya sederhana untuk pembelajaran, bukan standar tata fasilitas klinis.

Jiwa-AI · Asisten latihan

Latih kalimat terapeutik dan dapatkan umpan balik otomatis.

Menyiapkan Jiwa-AI…

Skenario klien

“Saya takut. Suara itu muncul lagi dan saya tidak tahu harus bagaimana.”

Balas sebagai perawat. Usahakan memvalidasi emosi, mengeksplorasi pengalaman, dan mengkaji keselamatan secara tepat.

Jiwa-AI akan memakai Generative AI jika backend telah dikonfigurasi. Jika backend belum tersedia, sistem beralih ke umpan balik demo lokal. Gunakan hanya kasus fiktif; jangan masukkan data pasien nyata.

Indikator umpan balik

Konteks penilaian: empati, eksplorasi pengalaman, keselamatan, sikap tidak menghakimi, dan tidak menguatkan isi halusinasi. Kunci API disimpan di server, bukan di browser.
