Mode demo
💬

Berlatih respons terapeutik

Balas pernyataan klien dengan bahasa empatik. Demo ini menggunakan aturan lokal sederhana, bukan model AI yang terhubung ke internet.

Jangan memasukkan nama, identitas, atau data pasien nyata. Untuk integrasi GenAI sungguhan, gunakan backend aman dan simpan API key di server, bukan di file HTML.
Skenario latihan

Klien merasa takut

“Saya takut. Suara itu muncul lagi dan saya tidak tahu harus bagaimana.”

EmpatiPertanyaan terbukaKeselamatan
Halo, saya Jiwa-AI versi demo. Ketik respons perawat Anda. Saya akan memberi umpan balik awal tentang empati, komunikasi netral, dan keselamatan.

Demo edukasi berbasis kata kunci; bukan layanan klinis, bukan diagnosis, dan tidak menggantikan supervisi dosen.
